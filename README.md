# 🌐 Language Translation Tool

A simple web-based Language Translation Tool developed as part of the Horizon TechX Artificial Intelligence & Data Science Internship Program.

## 📌 Project Description

This application allows users to enter text, select a source language and target language, and translate the text using an online translation service.

## ✨ Features

- Translate text between multiple languages
- Simple and user-friendly interface
- Source and target language selection
- Translation result display
- Error handling for invalid requests
- Supports languages including English, Telugu, Hindi, Tamil, Kannada, Malayalam, Spanish, French, German, Japanese, Korean and Chinese

## 🛠️ Technologies Used

- Python
- Streamlit
- Deep Translator
- MyMemory Translation Service
